# Documentación de Planner Fábrica

Este directorio reúne la documentación técnica y funcional de la versión publicada desde la rama `copia`.

## Contenido

- [Cambios de la rama `copia`](./CAMBIOS_RAMA_COPIA.md): alcance, archivos afectados, decisiones y validaciones.
- [Reportes de capacidad y cobertura](../server/README_REPORTES.md): fórmulas, fuentes de datos y endpoints del backend.

## Versión documentada

La rama `copia` parte de `main` e incorpora los reportes de cobertura y capacidad de fábrica, correcciones de compatibilidad SQL, mejoras de autenticación y accesibilidad, y la presentación visual de la fórmula de capacidad.

Los archivos de entorno y sus credenciales no forman parte del repositorio. Para ejecutar la aplicación se deben crear los `.env` locales a partir de la configuración indicada en el README principal.
